## 배경

*이 케이스 스터디는 실제 프로젝트를 기법과 결과 수준으로 재구성한 것입니다. 내부 시스템명·비공개 세부사항은 생략했으며, 측정된 수치는 실제와 동일합니다.*

세르비아 현지 생산 공장의 AOI(Automated Optical Inspection) 공정 데이터를 조회·시각화하는 모니터링 시스템을 개발했습니다. Figma 기반 UI/UX 설계부터 React 화면 구현, Spring Boot API 개발, MariaDB 연동까지 전 과정에 참여했고, 세르비아 현지 담당자와 영어로 소통하며 공정 계산식과 피드백을 반영했습니다.

## 문제

생산 품목별·호기별 AOI 공정 직행률(공정을 한 번에 통과하는 비율)을 확인하려면 담당자가 수기로 데이터를 집계해야 했습니다. 문제가 생긴 공정을 파악하는 시점이 늦어질 수밖에 없는 구조였습니다.

## 진행한 작업

### 1. Figma 기반 UI/UX 설계

현장 담당자가 실제로 보는 지표(품목별·호기별 직행률, 시간대별 추이)를 중심으로 대시보드 레이아웃을 설계했습니다.

### 2. ApexCharts·Plotly 기반 시각화

**ApexCharts**로 품목별·호기별 AOI 공정 직행률을 시계열 차트로 구현하고, 더 복잡한 다변량 비교가 필요한 화면에는 **Plotly**를 함께 사용해 인터랙티브 차트를 구성했습니다. 두 라이브러리를 화면 성격에 따라 나눠 쓰면서, 단순 추이는 가볍게, 다차원 비교는 인터랙션이 풍부하게 보여줄 수 있었습니다.

### 3. Spring Boot API + MariaDB 연동

**Java Spring Boot**로 공정 데이터 조회 API를 개발하고, **MyBatis**로 MariaDB 쿼리를 매핑했습니다. 프론트엔드 대시보드가 필요로 하는 집계 단위(품목별/호기별/시간대별)에 맞춰 API 응답 구조를 설계했습니다.

### 4. 현지 담당자와의 협업

세르비아 현지 담당자와 영어로 소통하며, 공정 계산식(직행률 산출 방식)과 실사용 피드백을 반영해 지표 정의를 다듬었습니다.
