## 배경

기술 쇼케이스를 겸한 개인 포트폴리오 사이트입니다. 기존의 정적 포트폴리오 대신 React Three Fiber(R3F)를 사용한 몰입형 3D 경험을 구축하여, 프런트엔드 개발뿐 아니라 3D 그래픽스, 국제화(i18n), DevOps 통합을 단일 프로젝트에서 보여줍니다.

**GitHub:** [Lajancia/Next14-R3F](https://github.com/Lajancia/Next14-R3F)

## 기술 하이라이트

### 1. React Three Fiber를 이용한 3D 장면 구성

사이트는 여러 인터랙티브 3D 장면을 포함합니다:

- **매크로 키보드** — 홈페이지 히어로: 키캡이 있는 상세한 키보드 모델(`.glb`), 커스텀 조명 및 포스트-프로세싱 효과로 렌더링
- **자전거** — 궤도 컨트롤이 있는 인터랙티브 3D 자전거 모델

각 장면은 독립적인 R3F 컴포넌트입니다:

```tsx
// 예: 3D 키보드 장면 컴포넌트 구조
import { Canvas } from '@react-three/fiber'
import { OrbitControls, Environment, useGLTF } from '@react-three/drei'

function KeyboardScene() {
  const { nodes, materials } = useGLTF('/keyboard.glb')
  return (
    <group>
      {Object.values(nodes).map((node, i) => (
        <mesh key={i} geometry={node.geometry} material={materials[node.name]} />
      ))}
    </group>
  )
}
```

### 2. i18next를 이용한 이중언어 지원

`i18next`를 사용한 완전한 한국어/영어 로컬라이제이션:
- 동적 라우트 기반 언어 감지 (`/en/pipeline`, `/ko/pipeline`)
- `accept-language` 헤더를 통한 서버사이드 언어 협상
- 페이지 컴포넌트별 네임스페이스 번역 파일

### 3. Panda CSS 스타일링

**Panda CSS**로 스타일링 처리 — 모던 CSS-in-JS 프레임워크:
- 타입-세이프 디자인 토큰
- 빌드 타임 제로-런타임 CSS 생성
- 미디어 쿼리 보일러플레이트 없는 반응형 변형

### 4. 인프라 타임라인

전용 Pipeline 페이지는 전체 CI/CD 인프라를 인터랙티브 타임라인 다이어그램으로 시각화합니다 — 사용자 → Nginx → Next.js → Jenkins → K3s → GitHub → Tailscale, 노드 사이를 흐르는 애니메이션 신호 패킷 포함.

## CI/CD 파이프라인

이 프로젝트는 완전한 DevOps 파이프라인을 포함합니다:

- **`dockerfile`** — pnpm을 사용한 멀티-스테이지 빌드 (deps → builder → runner)
- **`docker-compose.yml`** — 로컬 배포 설정
- **`Jenkinsfile`** — 자동 빌드, GHCR 푸시, GitOps 저장소 업데이트
- **`ecosystem.config.js`** — 프로덕션 PM2 프로세스 관리

## 주요 결정

**왜 Tailwind 대신 Panda CSS인가요?** Panda CSS는 빌드 타임에 타입-세이프 원자 스타일을 생성하여, Tailwind의 개발자 경험과 CSS-in-JS 라이브러리의 타입 안전성을 모두 제공합니다. 또한 애플리케이션 전반에 공유할 수 있는 설정 가능한 디자인 토큰을 지원합니다.

**왜 별도의 CI/CD 케이스 스터디인가요?** Next14-R3F 프로젝트는 원래 3D 포트폴리오와 Jenkins/K3s 파이프라인을 모두 포함하고 있었습니다. 각각이 시각화와 인프라라는 다른 엔지니어링 영역을 다루므로 별도로 문서화했습니다.
