## Context

*Internal system names and non-public details are omitted. The structure and the figures are as they are.*

I owned the deployment environment for a Next.js 14 recruiting service. The existing Docker image carried a full `npm`-based dependency install and the default Next.js build output, which made it large — and Jenkins deploys were slow in proportion to the image size.

## Problem

- The Docker image weighed **1.3GB**, and the time to build, transfer, and boot that image dominated the deploy.
- A single deploy took roughly **15 minutes**, making even a small change expensive to ship.

## What I did

### 1. Adopt Next.js `output: 'standalone'`

I switched to Next.js's standalone build output and rewrote the Dockerfile around it, producing a minimal image with only the dependencies actually needed at runtime. Stripping devDependencies, build-only tooling, and cached intermediates from the final image cut its size substantially.

### 2. Migrate npm → pnpm

I switched the package manager to pnpm to improve install speed and disk efficiency. pnpm's content-addressable store also improved cache reuse across CI builds.

### 3. Stabilize next-translate-based multilingual SSG builds

I reworked the build order and configuration so that next-translate-based multilingual pages generated reliably at build time in the SSG (static generation) environment.

## How a standalone build shrinks the image (measured on this site)

*The actual Illuminarean Docker images aren't something I can reopen today, so I reproduced the same `output: 'standalone'` technique on this portfolio site itself and measured it layer by layer. The mechanism is identical.*

This site uses Next.js `output: 'standalone'` in `next.config.ts`, which produces a minimal self-contained build with only the runtime dependencies needed to run the application.

The `Dockerfile` uses a three-stage build:

```dockerfile
# Stage 1: Install dependencies
FROM node:22-alpine AS deps
WORKDIR /app
COPY package.json package-lock.json* ./
RUN npm ci

# Stage 2: Build
FROM node:22-alpine AS builder
WORKDIR /app
COPY --from=deps /app/node_modules ./node_modules
COPY . .
RUN npm run build

# Stage 3: Minimal runner
FROM node:22-alpine AS runner
WORKDIR /app
COPY --from=builder /app/.next/standalone ./
COPY --from=builder /app/.next/static ./.next/static
COPY --from=builder /app/public ./public
```

The key line is `COPY --from=builder /app/.next/standalone ./`. Next.js's standalone output strips `devDependencies`, build tools, and cached intermediates, keeping only the required runtime — the same mechanism behind the 62% image-size cut at Illuminarean.

> **Note:** Docker daemon was not available on the measurement machine. The non-standalone estimate is based on typical `node_modules` footprint for a Next.js + MDX + Tailwind project. The standalone figure was measured from the actual `.next/standalone/` directory.
